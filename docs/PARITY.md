# Upstream capability parity

Statuses refer to this checkout, not to whether upstream research exists. `Implemented` means application behavior exists; it does not mean scientific validation or model parity. Synthetic test fixtures never count as real-source verification.

| SurgiVision | CVS-AdaptNet test/train | Full validation complete; single-frame product adapter implemented but gated | Isolated Python 3.10.21, PyTorch 2.1.0+cu118, TorchMetrics 1.2.0 and CUDA on the RTX 3050 ran the pinned upstream inference architecture. The source split contains 38 file names with identical all-black image bytes (one unique content hash); they remain in the official metric, and a unique-content sensitivity calculation produces the same AP. The 1,596,737,924-byte publisher-linked checkpoint has local SHA-256 `22fba6de08f78698cc8681ea4cdcf413342df83cbcfdd9842874e40f6583876f`. The current [official README](https://github.com/CAMMA-public/CVS-AdaptNet/blob/main/README.md) licenses the code repository CC BY-NC-SA 4.0, links the trained weights and says third-party models have their own licenses. It does not state checkpoint-specific terms or publish an independent checksum; the linked file resolves directly to a binary download. Do not infer weight rights from the code license; resolve checkpoint provenance and terms before enabling the Model Lab action. |

| FistulaGuard | Waveform, selected time region, PSD, spectrogram, descriptive integrity and same-record window comparison | Implemented; all 59 records selectable | Bounded waveform envelope and Welch PSD are calculated from the same measured source window. An on-demand time-frequency view uses 100 ms Hann windows with 50% overlap and a source-hashed, size-bounded matrix; frequency aggregation and relative-power display are disclosed, with no calibrated acoustic level inferred. Five channels are selectable and original time values are retained. A shadcn comparison panel calculates side-by-side descriptive feature values from two equal-length windows of the same verified recording and channel; it does not label either window better. A source-hashed cohort audit found finite values across all recordings and 306 intervals over a descriptive 0.1% tolerance in 49 of 59 recordings (maximum 11 in one recording); the selected-window integrity panel reports counts without grading signal quality. No pooled cohort calculations, stenosis classifier, synthetic waveform or diagnostic interpretation is exposed. See [`fisav-window-integrity.json`](evidence/fisav-window-integrity.json). |
