# UX-04 Academy: home and specialty path

**Status: Implemented for review.** The Academy home and specialty path use the signed-in student's actual local API state. This preview has no assigned lesson, XP, or award, so those empty states remain visible.

## What changed

- Rebuilt the Academy landing hierarchy around a warm cream welcome, one API-derived next-investigation action, the source collection in focus, and a chronological path list.
- Kept the three research sources distinct. A path exposes its own assignment counts, source, objective, and state; no clinical mastery, shared patient storyline, practice streak, or unlocked lesson is implied.
- Put released cohort assignments and due dates in a separate list. Empty and request-error states continue to come from the existing Academy endpoints.
- Reworked the specialty path into an ordered lesson route. Each row only represents a published assignment returned for the signed-in student and links to that assignment’s mission.
- Display XP only when the student’s server preference is enabled. Render an achievement badge only when the existing API returns an earned award and achievement opt-in is enabled. No threshold, badge, or XP value is generated by the UI.
- The Progress record now uses Trophy UI's Achievement Grid for API-returned earned awards only. Opted-out and opted-in-empty states have been reviewed at desktop, tablet and phone sizes; no locked/example award is included.
- Kept the Base Nova Card, Button, Badge, Empty, Alert, Skeleton, and other installed shadcn primitives. No package was added.
