# MEDFORGE MVP scope

Updated 2026-10-09. This document transcribes the v0.8 product materials into the state implemented in this checkout. It is not evidence that the user approved every proposed architecture choice; the source set marks the product architecture as not locked.

## Product boundary

MEDFORGE is a local-first research and education workspace for three separate evidence domains: SurgiVision, DoseTwin and FistulaGuard. It is not a patient-care application, diagnostic system, treatment planner, clinical certification product or automated tutor. It does not join the three research datasets into a shared patient journey.

## Must-have vertical slices

| Slice | Current state | Evidence and limits |
|---|---|---|
| Shared workspace and case registry | Implemented; clinician/researcher, educator, and learner entry paths are explicit | The landing page presents the Professional Studio for clinicians and medical researchers, plus separate educator and student routes. The professional workbench leads with verified per-source material and task-first review links. Local case registry includes 1,933 Endoscapes frame records, one OpenKBP case, and 59 FiSaV recordings; units/counts stay separate. Global `Ctrl+K`/`⌘K` search finds source cases, datasets, specialties and workspaces, then opens a filtered registry for broad matches. Registry search is shareable through its query URL. Professional shell, source inventory, case header, and methods table compose Tailwind utilities with shadcn Base Nova components. SurgiVision's source-frame view was reviewed at desktop and phone widths; DoseTwin and FistulaGuard charts/heatmap were reviewed at laptop, tablet and phone widths, with DVH/PSD arrow-key point inspection. A broader annotation-navigation and reduced-motion interaction review remains open. Scientific visualization layers retain focused custom styles. |
| DoseTwin real-source review | Implemented for `pt_201` | Real CT/dose/ROI arrays, linked index-space slices, ROI statistics/DVH, hashes, report export and one-case official metric cross-check. The local smoke verifies 10 non-empty source ROI DVHs and all 36 CT/dose/ROI planes for shape, units, cumulative values and hashes. No predictions, DICOM orientation or clinical plan. |
| SurgiVision real-frame review | Implemented for all 1,933 annotated BBox201 keyframes | Source images, COCO boxes and image-level labels, RLE masks where annotated, original-pixel selection, frame/split/source hashes. Continuous video and model output are not installed. |
| FistulaGuard real-signal review | Implemented for 59 recordings | Measured channels, bounded windows, Welch PSD, on-demand selected-window spectrogram, descriptive features, selected-window integrity and a same-record/same-channel feature comparison across two equal-length windows. The waveform, PSD and time-frequency view were reviewed at laptop (1280px), tablet (768px) and phone (390px) widths; PSD point inspection works with arrow keys. Units remain uncalibrated; spectrogram color is relative to the displayed peak; integrity counts are not a quality grade; comparison is descriptive and does not imply better/worse or diagnosis; no stenosis classifier. |
| Educator-to-learner flow | Implemented; temporary signed-in educator/student flow and responsive screens reviewed in isolation | Owner-scoped drafts, immutable versions, source-term check, cohorts, assignments, case-scoped viewer evidence, student redaction, manual rubric review and delayed debrief. Educator review now presents student answers in the authored lesson sequence; the authentic FiSaV workflow regression uses reverse-sorting opaque block IDs to verify this. OpenKBP publication remains blocked. Fresh isolated review confirmed the current Progress page renders the Trophy points badge only after opt-in and shows the activity-award empty state; current phone-width review of that page remains open. |
| Evidence report | OpenKBP run reports; FiSaV comparisons indexed; SurgiVision frame reports indexed | OpenKBP saved runs preserve source hashes, method, selected viewer state and limitations. Persisted FiSaV same-record comparisons appear in the shared Reports index with paginated history and export as attributed JSON with exact source hash, sample rate, both measured windows and descriptive metrics. SurgiVision frame reports are saved from a server-verified frame and preserve source/split/hash, original-pixel annotations, image-level labels with annotator-mean interpretation, display state, citation, license and limitations without embedding the image; save/export actions are hidden in learner mode. No report claims model comparison where no prediction exists. |
| Experiment comparison | Partial | FistulaGuard same-record measured-window comparisons are persisted and retrievable with source provenance. General compatible-model-run and two-dose comparisons await additional verified artifacts; no prediction is manufactured. |
| CVS-AdaptNet research inference | Isolated CUDA worker and source-bound single-frame API adapter implemented; execution gated | Actual 409-frame validation plus a selected-frame evidence run are recorded. API persists idempotent runs with frame, annotation, prompt, model and dataset provenance. Execution stays blocked until an independently verified checkpoint hash and checkpoint-specific use terms are supplied. |
| API-to-TypeScript contract | Generated OpenAPI and frontend schema types implemented | Pydantic generates `contracts/openapi-implemented.json`; `openapi-typescript` generates frontend response schemas. `npm run contracts:check` checks drift. Specialized UI result projections remain narrower than the API `RunRecord` envelope. |
| shadcn component system | Implemented | Generated Base Nova Sidebar, Card, Input, Select, Checkbox, Toggle, Slider, Combobox, Field, Table and Chart primitives compose the workspace shell, domain/source panels, educator flows, chart data companions and learning surfaces. Recharts renders the DVH and PSD; uPlot renders dense signals. MEDFORGE-specific measurements, provenance and analysis limits shape the views; semantic theme tokens style the components. |
| Frontend preference contracts | Implemented | Vitest tests the per-case/per-frame/per-record saved-view parsers, including invalid bounds and legacy defaults. Interactive reload, keyboard and responsive behavior still requires browser review. |
| Server-state cache | Implemented for shared registries, learning summaries and DoseTwin viewer data | TanStack Query deduplicates requests, retries one transient failure, caches slices by case/axis/index/ROI and DVHs by case/ROI; local login/logout clears cached data. Remaining specialty viewer fetches keep their request-specific debounce and object-URL cleanup behavior. |

## Future research scope retained in `PARITY.md`

Authentic SurgiVision model families and temporal methods; DoseTwin prediction workers, OpenKBP-Opt archived outputs and optimization; PortPy IMRT/VMAT/solver integrations; cohort-wide FistulaGuard analysis and patient-disjoint classifier evaluation; queued workers, cancellation, cloud storage, institutional identity and collaborative review remain future or blocked. Each requires verified code, data rights, dependencies, checkpoints/solver availability and a real smoke test before its status changes.
