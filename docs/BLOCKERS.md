# External prerequisites and real blockers

## Research data access

- **OpenKBP:** one complete validation case (`pt_201`) is installed locally from the official repository at commit `ce625e62f3b04203f22bd9d1634f3e8fb0245e46`. All 14 files match the repository Git blob IDs; SHA-256 values are recorded in `docs/openkbp-pt201-manifest.json`. Rechecked the [official README](https://github.com/ababier/open-kbp/blob/master/README.md) on 2026-10-09: it describes the data and `provided-data` folder, while the repository advertises an MIT code license; no separate dataset license grant was found there. Do not infer data rights from the code license. Keep this case in local research/education use; do not redistribute. Check the applicable data terms before external display, publication or commercial use. The pinned official evaluator has been used for one-case numerical comparison; details are in `docs/openkbp-pt201-validation.json`.
- **Endoscapes:** all 1,933 BBox201 annotated keyframes and the original train/val/test COCO split files are installed locally and checksum-validated. The archive contains 2,248 official compressed RLE segmentations. The source is available for non-commercial scientific research under CC BY-NC-SA 4.0. The full ZIP, continuous video and unannotated intermediate frames remain uninstalled; check public-display and redistribution conditions before sharing any demo, and preserve attribution and split identity.
- **FiSaV:** the official OSF dataset (`10.17605/OSF.IO/HYPFR`) and CC BY 4.0 file license are verified. All 59 genuine CSV recordings (`pat001.csv`–`pat059.csv`, 8,144,854,743 uncompressed bytes) are installed locally; the 2.27 GB ZIP and demographics workbook were not stored. Per-record sizes, SHA-256 values, and member names are preserved in `data/fisav/medforge-source-manifest.json`. The viewer lets users select a source recording and inspect ECG/four raw PZT channels, a bounded measured waveform, Welch PSD, and descriptive sample-window statistics. Median sampling rate is 10 kHz; original timestamps retain rare 1% interval variations. Units/calibration are unspecified. No stenosis outcome is inferred from the occlusion field; no classifier, pooled analysis or diagnostic interpretation is exposed. See the in-app source links and local manifest for attribution.

## Product security gate

Operator-provisioned local educator/student login, expiring/revocable bearer sessions, and role checks protect the education routes. The local workflow supports owner-scoped drafts, learner-safe previews, immutable publication revisions, source-term attestation, educator-owned cohorts, assignments, student attempts, idempotent submission and grading, delayed debrief and progress records. Grade retries require an attempt-scoped key; identical retries replay a receipt, while intentional corrections use a fresh key. Isolated signed-in end-to-end reviews with temporary accounts and databases verified Endoscapes learner redaction, selected-frame evidence, educator rubric scoring, delayed source-annotation release, and a FiSaV `pat001` waveform mission with selected PZT2 evidence and a criterion-scored debrief. Academy pathway index and detail now have desktop/tablet/phone responsive review plus keyboard activation of a focused pathway link; assigned lesson navigation was confirmed in the earlier assigned-work review. The regular local databases contain no provisioned learning accounts, so a real user cohort still needs local operator setup before that workspace can be used. This is not production identity, general API RBAC or a legal permissions determination: research routes remain locally accessible, and the API must stay on loopback. OpenKBP publication remains blocked. External hosting stays disabled.
