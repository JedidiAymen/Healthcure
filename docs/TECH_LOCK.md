# Local implementation lock

- Web: React 19, Vite, TypeScript, Tailwind CSS 4, generated shadcn/ui Base Nova components. The app shell is composed from generated `Sidebar*` primitives in `src/components/Shell.tsx`; research and Academy cards use generated Card primitives. Educator forms use composed Field, Input, Select and Checkbox primitives. Project styling is applied through semantic shadcn theme tokens and composition classes. The shadcn Chart composition themes Recharts for the DoseTwin DVH and FiSaV PSD, each with a shadcn Table data companion that exposes the same plotted values and source/method context; the larger PSD table mounts on demand. uPlot powers dense FiSaV waveforms; the selected-window spectrogram uses a bounded local canvas heatmap with an accessible source-value table. dnd-kit sorts educator blocks, Motion is limited to Academy, and Trophy UI contributes local shadcn achievement/points components. TanStack Query owns shared server-state reads and DoseTwin case/axis/index/ROI slice and DVH cache keys; login/logout clears the query cache so learner/educator data cannot survive a local session change. Vitest 5 runs isolated parsing contracts for persisted viewer preferences. Exact JavaScript package versions are locked in `package-lock.json`.
- API: FastAPI modular monolith, Pydantic v2, SQLite schema migrated from the v0.8 reference; local NumPy loader for OpenKBP arrays.
- Workers: research-specific legacy environments remain isolated; no pretrained model dependencies are installed in the API environment.
- Data: no research dataset or model checkpoint is vendored. Operator-configured sources remain outside the repository.
- Bindings: API and Vite default to `127.0.0.1`; the API CORS allowlist is limited to local development origins. Operator-provisioned local sessions protect selected Academy/Educator routes; general research API routes do not have full RBAC. Keep the API on loopback and do not expose it to a network.
- DoseTwin geometry: index-space only. No DICOM coordinate frame, physical orientation, delivered dose or clinical recommendation is asserted. One installed validation case was cross-checked against the pinned official evaluator for benchmark metric parity; see `docs/openkbp-pt201-validation.json` for scope and limits.
- Academy: XP and activity-achievement preferences are separate, private, and off by default. The single current badge describes a first reviewed evidence investigation, never clinical competence. Rubric-dimension summaries are coursework progress only. No public leaderboard is enabled.
