## Start locally

First setup: create `apps/api/.venv`, install `apps/api/requirements-test.txt`, and run `npm ci` from the project root. Then launch both services with `./scripts/start_local.sh`; open `http://127.0.0.1:5173`. The launcher selects installed source folders and defaults the database to `data/local.sqlite3`. Re-acquire and re-hash OpenKBP `pt_201` with `python scripts/acquire_openkbp_pt201.py` if its ignored folder is missing.

The API is local-only reference software. Selected education routes use provisioned local-role authentication, while general research routes have no account authorization. Do not expose it to a network. The frontend can run without the API and reports the disconnected state.
