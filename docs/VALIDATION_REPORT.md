## DoseTwin numerical check

- **Source case:** OpenKBP `pt_201`; upstream commit `ce625e62f3b04203f22bd9d1634f3e8fb0245e46`.
- **Method:** compare MEDFORGE's computed case metrics with the pinned official OpenKBP evaluation implementation included under `references/open-kbp-validation/`.
- **Result:** 23/23 mean, OAR D0.1cc, and PTV D99/D95/D1 comparisons passed; largest absolute difference was `0.0000076471 Gy`. Same-dose evaluator scores were 0.0/0.0 and serve only as a loader/evaluator sanity check.
- **Geometry:** array shape `[128,128,128]`, spacing `[5.422,5.422,3.0] mm`. The app represents processed array indices only; no native DICOM origin or orientation is available.
- **Record:** [`openkbp-pt201-validation.json`](openkbp-pt201-validation.json), produced by `scripts/crosscheck_openkbp_pt201.py`.
- **Limits:** this is one validation case and numerical protocol parity. It says nothing about model prediction accuracy, treatment validity or clinical use.
- **Visual evidence:** [openkbp-pt201-dose-twin-local.png](evidence/openkbp-pt201-dose-twin-local.png) captures the real `pt_201` CT, reference-dose and ROI overlays in three linked array planes plus the Brainstem DVH. It is a local development artifact; OpenKBP data rights are not established for external display or redistribution.

## FistulaGuard source processing

- All 59 CSV recordings were acquired from the official OSF archive with bounded byte-range extraction; archive CRC and per-file SHA-256 were checked. The recorded median rate is 10 kHz while original timestamps are preserved, including observed small interval variations.
- `scripts/audit_fisav_window_integrity.py` reran the production loader and manifest hash checks over all 59 installed records. Every time/channel value was finite. Using a descriptive 0.1% tolerance against the median-derived 10 kHz interval, 49 records contain at least one deviating interval (306 total; maximum 11 in one recording). The per-record counts and source hashes are preserved in [`evidence/fisav-window-integrity.json`](evidence/fisav-window-integrity.json). These counts are not a signal-quality grade or clinical threshold.
- The same-record window-comparison endpoint is tested for hash/channel/sample compatibility, accurate signed feature differences, idempotent save, list/detail retrieval, learner access denial and rejection of identical or out-of-range windows. A final isolated API run against authentic `pat011` saved and reopened two 5,000-sample raw PZT1 windows (starts 0 and 10 seconds), with the same source SHA-256 and seven computed feature differences. Its temporary database was deleted afterward; no sample row was added to the normal app database. This establishes source calculations and artifact persistence, not clinical meaning.
- Prior source checks loaded `pat002` and `pat059` summaries and selected-window features. Current automated tests verify the measured-window waveform, Welch PSD, descriptive features, bounded slices and provenance using controlled fixtures. FistulaGuard's real `pat001` waveform workspace was visually reviewed at desktop (1280px), tablet (768px) and phone (390px) widths; waveform and PSD panels stack without page-level horizontal overflow. An isolated learner opened a published `pat001` lesson, selected measured PZT2 evidence for 0–10 seconds, submitted source observations, and received an educator-scored debrief after criterion review. The score and accounts existed only in a disposable local database, which was removed.
- Physical units/calibration and a stenosis label are not established. No classifier or diagnostic claim is validated.
